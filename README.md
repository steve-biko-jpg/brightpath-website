
# BrightPath Learning Centre Website

A responsive website concept for BrightPath Learning Centre, a fictional tutoring centre in Kigali, Rwanda.

## Live Website

https://steve-biko-jpg.github.io/brightpath-website/

## Project Goals

- Present the learning centre and its services.
- Explain the available tutoring programmes.
- Help parents and learners get in touch.
- Provide a user-friendly experience on desktop and mobile devices.

## Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, and responsive design.
- **Git** — Version control.
- **GitHub** — Source code hosting.
- **GitHub Pages** — Website hosting.

## Project Features

- Responsive page layout.
- Navigation between website sections.
- Service cards for tutoring programmes.
- About and contact sections.
- Mobile-friendly styling.

## Run Locally

### Prerequisites

- Git installed on your computer.
- Python installed to run a local development server.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/steve-biko-jpg/brightpath-website.git
   ```

2. Navigate to the project folder:

   ```bash
   cd brightpath-website
   ```

3. Start a local server on Windows PowerShell:

   ```powershell
   py -m http.server 8000
   ```

4. Open this address in your browser:

   http://localhost:8000

Press `Ctrl+C` in PowerShell to stop the server.
